# pollutant-removal-rsm-optimization
R code and reproducible analysis for response surface modeling and optimization of pollutant removal efficiency.
# RSM-Based Optimization of Pollutant Removal Efficiency

This repository contains the R code and supporting materials used for the
response surface methodology (RSM) analysis and optimization reported in
the associated study.

## Repository contents

- `analysis/0130_en_final_latest.Rmd`
  Main R Markdown file containing response surface modeling,
  statistical analysis, model diagnostics, and optimization.

- `data/data_collection.csv`
  Experimental dataset used in the analysis.

## Software

The analysis was conducted in R.

Main packages include:

- tidyverse
- rsm
- ggplot2
- dplyr
- plotly
- rBayesianOptimization
- GPfit

## Reproducing the analysis

1. Clone or download this repository.
2. Open the project in R/RStudio.
3. Install the required R packages.
4. Run or knit `analysis/0130_en_final_latest.Rmd`.
